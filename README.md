# nfl-big-data-bowl-2027
2027 NFL Big Data Bowl Repository


## Combine movement visualizations

Open `docs/index.html` to explore offensive Combine drills, player movement comparisons, and metric distributions. All required chart images are included; no build or installation is needed. Raw tracking datasets and analysis CSVs are not included in the website.

To publish with GitHub Pages, merge this branch and choose **Settings → Pages → Deploy from a branch → main → /docs**.

The metrics are exploratory. Full recordings can include drill exits, and automatically detected turns are not verified route breaks. These charts do not establish predictive relationships with NFL performance.
